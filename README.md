## ▸ WHAT THIS IS

An open-world reconstruction of the mindscape documented in *DO-LOON-AI EXPRESS: The Mind Experiment* and *The Hidden Map of the Self*.

You are Subject **IT-041**. Lunaris walks beside you. The moon keeps its own calendar — the dates are real, and the full moon of **12 April 2025, 22:15** matters more than the Institute admits.

Four locks. Seven rites. One file the machine will write about *you*.

Whatever you write inside the rites **never leaves your device**. The simulation keeps no records. The Institute was never given access. That was the whole point.
